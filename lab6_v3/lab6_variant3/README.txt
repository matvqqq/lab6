ЛАБОРАТОРНА РОБОТА №6 — ВАРІАНТ 3

Цей варіант перероблено за візуальними зразками та вимогами з наданого PDF.

Як відкрити:
1. Розпакуйте архів у будь-яку папку.
2. Відкрийте index.html у Google Chrome.
3. На головній сторінці натискайте на потрібне завдання.
4. Для повернення натискайте «На головну».

Файли:
index.html, style.css — головна сторінка;
task1.html, task1.css — блоки, як у рядку варіанта 3 таблиці 1;
task2.html, task2.css — поведінка для варіанта 3 таблиці 2;
task3.html, task3.css — форма реєстрації за макетом і точними стилями PDF;
task4.html, task4.css — горизонтальне та вертикальне меню;
task5.html, task5.css, weather-example.png — зразок накладання картки погоди з PDF;
task6.html, task6.css — попап без JavaScript, з розширенням More;
control.html — відповіді на 15 контрольних запитань.

Завдання 4 використовує Google Material Icons з Google Fonts, тому для піктограм потрібен інтернет.
Завдання 6 реалізовано лише HTML і CSS, без JavaScript та зовнішніх бібліотек.\n
